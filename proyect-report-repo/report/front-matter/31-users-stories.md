Entonces la venta queda registrada, el stock de 10 kg se reduce en 2 unidades y aparece en el resumen del día. **Escenario 2:** Dado que el distribuidor registra la venta a fiado del cliente 'Rosa Huanca' que ya debe S/. 45. Cuando selecciona Pago: Fiado e ingresa el cliente. Entonces el sistema muestra 'Cliente: Rosa Huanca – Deuda actual: S/. 45. ¿Confirmar venta?' antes de guardar. | |
| US-55 | Registro de clientes con fiado y control de deudas | Como distribuidor, quiero registrar qué clientes me deben dinero (fiado) indicando nombre, monto adeudado, fecha del fiado y descripción de lo que se llevaron, para llevar un control claro de mis cobranzas pendientes y evitar olvidar quién me debe. | **Escenario 1:** Dado que el distribuidor registra el fiado: Cliente: Juan García / Tipo: 10 kg / Cantidad: 2 / Monto: S/. 50 / Fecha: hoy. Cuando guarda el fiado. Entonces el registro queda guardado y Juan García aparece en la lista de clientes con fiado con deuda total: S/. 50. **Escenario 2:** Dado que el distribuidor intenta registrar un fiado sin ingresar el nombre del cliente. Cuando presiona 'Guardar'. Entonces el sistema muestra 'El campo Cliente es obligatorio' y no realiza ningún registro. | |
| US-56 | Registro de pagos de clientes para actualizar el saldo de fiado | Como distribuidor, quiero registrar el pago que realiza un cliente (total o parcial) para que su saldo de deuda se actualice automáticamente y pueda ver en todo momento cuánto debe cada uno. | **Escenario 1:** Dado que el cliente Juan García tiene una deuda de S/. 50 y paga S/. 30. Cuando el distribuidor registra: Cliente: Juan García / Monto pagado: S/. 30. Entonces el saldo de Juan García se actualiza a S/. 20 y el pago queda registrado en el historial del cliente. **Escenario 2:** Dado que el cliente Rosa Huanca tiene una deuda de S/. 45 y paga S/. 45. Cuando el distribuidor registra el pago total. Entonces el saldo de Rosa Huanca pasa a S/. 0, su estado cambia a 'Sin deuda', desaparece de la lista de fiados pendientes y queda en el historial. | |
| US-57 | Digitalización completa de operaciones del distribuidor | Como distribuidor, quiero registrar digitalmente en la plataforma todos mis inventarios, ventas y fiados, para reemplazar los cuadernos y hojas sueltas por un sistema centralizado, más rápido, claro y confiable. | **Escenario 1:** Dado que el distribuidor usa la plataforma para registrar una venta de 5 balones de 10 kg. Cuando guarda la operación. Entonces el sistema registra la venta, actualiza el stock, registra el responsable y la hora, y el registro queda disponible en el historial sin necesidad de anotar en papel. **Escenario 2:** Dado que el distribuidor intenta guardar dos veces la misma venta (5 balones de 10 kg) en 30 segundos. Cuando presiona 'Guardar' la segunda vez. Entonces el sistema muestra 'Posible duplicado detectado: misma operación registrada hace menos de 60 segundos. ¿Desea continuar?' y espera confirmación antes de proceder. | |

Cuando hace clic en la sección 'Fiados pendientes'. Entonces el sistema navega directamente al módulo 'Fiados' mostrando la lista completa de clientes con deuda. | |
